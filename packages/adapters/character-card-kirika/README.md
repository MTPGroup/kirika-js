# @kirika-js/adapter-character-card-kirika

kirika 的角色卡适配器

## 安装

```bash
pnpm add @kirika-js/adapter-character-card-kirika
```

使用 npm 或 Yarn：

```bash
npm install @kirika-js/adapter-character-card-kirika
# or
yarn add @kirika-js/adapter-character-card-kirika
```

## 运行环境

- Node.js >= 22.12

## 支持格式

- PNG
- RawJson
