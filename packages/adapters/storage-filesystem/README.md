# @kirika-js/adapter-storage-filesystem

kirika 的文件系统对象存储适配器

## 安装

```bash
pnpm add @kirika-js/adapter-storage-filesystem
```

使用 npm 或 Yarn：

```bash
npm install @kirika-js/adapter-storage-filesystem
# or
yarn add @kirika-js/adapter-storage-filesystem
```

## 运行环境

- Node.js >= 22.12
