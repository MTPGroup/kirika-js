# @kirika-js/adapter-character-card-external

kirika 的 外部角色卡适配器

## 安装

```bash
pnpm add @kirika-js/adapter-character-card-external
```

使用 npm 或 Yarn：

```bash
npm install @kirika-js/adapter-character-card-external
# or
yarn add @kirika-js/adapter-character-card-external
```

## 运行环境

- Node.js >= 22.12

## 支持格式

- PNG(TavernCard v2/v3)
- CharX(Risu)
- Voxta(.voxpkg)
- RawJson
